# State v. Land

## Majority (s/Beaslev. J.)

ORDER
The defendant’s petition for discretionary review as to additional issues in this matter is allowed only as to the following issue: whether the Court of Appeals imposed a standard of review that is inconsistent with the standard set out in Strickland v. Washington. The remaining issues are denied.
